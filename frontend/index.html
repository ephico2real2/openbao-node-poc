Secure Notes

A small notes app whose Postgres and Redis credentials are never on disk or in the environment. Watch them load, rotate and recover, and try to leak them.

Secret values are being written to the log. LOG_REVEAL_SECRETS is on, so the debug credential lines print real passwords. Lab troubleshooting only: turn it off when you are done. The app refuses this setting in production.

  1. Browsernever sees a credential
  2. Node appIAM role, no keys
  3. In-memory cacheTTL + refresh on auth failure
  4. Secrets Managervia VPC endpoint · KMS

The app uses those credentials to reach Postgres and Redis over TLS (in AWS).
