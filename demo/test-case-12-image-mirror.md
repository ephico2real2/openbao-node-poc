# Test case 12 — Mirror the images to your own registry

[← all test cases](README.md)

**What it proves:** a cluster that cannot reach ghcr.io or Docker Hub can run the stack from its own registry: one command copies all four images and writes an overlay that pulls only from there.

**Catalogue IDs:** K4 ([TEST-CASES.md](../docs/TEST-CASES.md)) · **Proven in CI by:** `mirror` · **Evidence from:** [CI run 39169755271](https://github.com/ephico2real2/openbao-node-poc/actions/runs/39169755271): [mirror output](https://github.com/ephico2real2/openbao-node-poc/blob/ci-captures/2026-10-18T2159Z_ci_run39169755271-1_mirror-logs/mirror.txt), [layer check](https://github.com/ephico2real2/openbao-node-poc/blob/ci-captures/2026-10-18T2159Z_ci_run39169755271-1_mirror-logs/mirror-check.txt), [generated overlay](https://github.com/ephico2real2/openbao-node-poc/blob/ci-captures/2026-10-18T2159Z_ci_run39169755271-1_mirror-logs/mirror-overlay.yaml)

## Steps

```bash
skopeo login registry.example.com        # or podman login / oc registry login
scripts/mirror-images.sh registry.example.com/team/secure-notes
KUBECTL=oc scripts/k8s-deploy.sh deploy/k8s/overlays/mirror
```

Your run copies the published images (`ghcr.io/ephico2real2/openbao-node-poc/app` and `/aws-mock` at `latest`) plus `postgres:16` and `redis:7-alpine` from Docker Hub. `MIRROR_TOOL=oc` uses `oc image mirror` instead of skopeo.

- **OpenShift** (default `BASE_OVERLAY=openshift`): create the project first, `oc new-project secure-notes`.
- **kind / any Kubernetes**: `BASE_OVERLAY=kind scripts/mirror-images.sh …`, then `scripts/k8s-deploy.sh deploy/k8s/overlays/mirror` with plain `kubectl` (no `KUBECTL=oc`).

## Evidence from the run

CI mirrors into a throwaway registry on the runner, copying the images it just built straight from Docker (`SRC_APP=docker-daemon:…`), so the sources below differ from yours. The script copies, writes the overlay, and checks every image in it comes from the mirror:

```
== mirroring with skopeo to localhost:5001/secure-notes
  docker-daemon:secure-notes-app:dev -> localhost:5001/secure-notes/secure-notes-app:latest
  docker-daemon:secure-notes-aws-mock:dev -> localhost:5001/secure-notes/secure-notes-aws-mock:latest
  docker-daemon:docker.io/library/postgres:16 -> localhost:5001/secure-notes/postgres:16
  docker-daemon:docker.io/library/redis:7-alpine -> localhost:5001/secure-notes/redis:7-alpine
  ok    localhost:5001/secure-notes/postgres:16
  ok    localhost:5001/secure-notes/redis:7-alpine
  ok    localhost:5001/secure-notes/secure-notes-app:latest
  ok    localhost:5001/secure-notes/secure-notes-aws-mock:latest
== wrote deploy/k8s/overlays/mirror — deploy with:  KUBECTL=oc scripts/k8s-deploy.sh deploy/k8s/overlays/mirror
```

Then CI compares each copy with the original, layer by layer (uncompressed digests):

```
  ok    localhost:5001/secure-notes/secure-notes-app:latest (10 identical layers)
  ok    localhost:5001/secure-notes/secure-notes-aws-mock:latest (8 identical layers)
  ok    localhost:5001/secure-notes/postgres:16 (14 identical layers)
  ok    localhost:5001/secure-notes/redis:7-alpine (7 identical layers)
```

The overlay it generated:

```yaml
# GENERATED by scripts/mirror-images.sh (not committed): overlays/openshift
# with every image pulled from localhost:5001/secure-notes.
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
  - ../openshift
images:
  # the names the openshift overlay uses (published, then local build names)
  - { name: ghcr.io/ephico2real2/openbao-node-poc/app, newName: localhost:5001/secure-notes/secure-notes-app, newTag: "latest" }
  - { name: ghcr.io/ephico2real2/openbao-node-poc/aws-mock, newName: localhost:5001/secure-notes/secure-notes-aws-mock, newTag: "latest" }
  - { name: secure-notes-app, newName: localhost:5001/secure-notes/secure-notes-app, newTag: "latest" }
  - { name: secure-notes-aws-mock, newName: localhost:5001/secure-notes/secure-notes-aws-mock, newTag: "latest" }
  - { name: docker.io/library/postgres, newName: localhost:5001/secure-notes/postgres, newTag: "16" }
```
